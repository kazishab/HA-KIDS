# Brain Games Kids - Kids Brain Development App

[![Built by HA TECH BD](https://img.shields.io/badge/Built%20by-HA%20TECH%20BD-blue)](https://github.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An interactive web application designed to develop children's intelligence and cognitive skills. Perfect for kids aged 3-10 years old.

## 🎮 Games Included

### 1. **Memory Match** 🎴
- Flip cards and find matching pairs
- **Skills Developed:**
  - Memory power
  - Concentration and focus
  - Visual recognition

### 2. **Number Patterns** 🔢
- Identify number sequences and find the next number
- **Skills Developed:**
  - Logical thinking
  - Problem solving
  - Mathematics skills

### 3. **Speed Match** ⚡
- Answer questions quickly and accurately
- **Skills Developed:**
  - Quick thinking
  - Decision making
  - Reaction time

### 4. **Sudoku** 🎯
- Solve number puzzles (4×4 grid)
- **Skills Developed:**
  - Logical thinking
  - Strategic planning
  - Patience and concentration

## 🎯 Game Modes

Each game features three playable modes:

- **VS Computer** 🤖 - Play against AI opponent
- **Pass & Play** 👥 - Two players on same device
- **Online** 🌐 - Play with friends online using 4-digit room codes

## 🚀 Getting Started

### Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for online mode)

### Quick Setup

#### Option 1: GitHub Pages (Recommended)
```bash
# Repository is already set up
# Just fork/clone and enable GitHub Pages
# Live at: https://YOUR_USERNAME.github.io/brain-games-kids/
```

#### Option 2: Local Testing
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/brain-games-kids.git
cd brain-games-kids

# Start a local server
python -m http.server 8000

# Open in browser
# http://localhost:8000
```

This app uses Firebase Realtime Database:

1. Firebase Console: https://console.firebase.google.com/
2. Create new project: "ha-kids"
3. Enable Realtime Database
4. Enable Anonymous Authentication
5. Configure Database Rules (Test Mode for development)

Firebase credentials are already configured in `js/firebase-config.js`
